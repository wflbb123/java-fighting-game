Java Console Fighting Game

A small but complete turn-based battle game in Java — account system, character building, waves of enemies, and a progression loop. Supports English / 中文 out of the box.

★ View on GitHub Read the docs

What's inside

Everything you need for a tiny but fun roguelite-ish loop.

🔐

Account system

Register / login with validation (length, charset), captcha on login, and 3-strike account lockout.

👤

Guest mode

Jump straight into battle without registering. Perfect for a quick test.

🎯

Character building

Allocate 20 skill points across HP / Attack / Defence to shape your hero.

⚔️

Turn-based combat

Attack, super-attack (costs HP), or heal — fight randomly matched enemies each round.

📈

Progression

Enemies grow stronger each round; win 3 in a row for an attribute boost.

🌐

Bilingual (EN / 中文)

Pick a language at startup; all UI text switches via a tiny i18n helper.

Build & run

Requires JDK 8+. Tested with JDK 25.

1 · Compile

# from the demo/ directory javac -d bin src/App.java src/i18n/*.java src/domain/*.java src/ui/*.java

2 · Run

java -cp bin App

What happens

$ java -cp bin App // you'll be asked to pick a language first Choose language / 选择语言: 1. English 2. 中文 // then the login menu appears... Welcome to the login page! Choose an option: 1. Login 2. Register 3. Play as guest 4. Exit

Known issues & ideas

Documented in OPTIMIZATION.md — a few highlights:

  • fixedSingle Scanner — Use one shared Scanner across the flow to avoid NoSuchElementException from buffered input.
  • fixedshow() output — Attribute display after a win streak is now printed correctly.
  • ideaPersistence — Accounts and progress are in-memory only; add file/DB storage.
  • ideaInput safety — nextInt() crashes on non-numeric input; add validation loops.
  • ideaCaptcha — The verification code is printed in plaintext; generate & check it properly.
  • ideaLICENSE — Add a LICENSE file to make the repo clearly open-source.
